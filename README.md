# event-command-center

Minimal Python implementation of a **Real-Time Event Operations Command Center** with:

- **Real-time operations tracking** (zone occupancy + incident feed)
- **Crowd forecasting** (next-step occupancy prediction)
- **QR identity** (signed token issue/validation for attendee identity)

## Run tests

```bash
python -m unittest discover -s tests -p "test_*.py"
```
